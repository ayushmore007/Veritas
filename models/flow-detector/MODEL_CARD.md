# Veritas flow detector — model card (v20261112-194700)

**Task:** classify a single QUIC/UDP flow as `benign` or `malicious` from behavioural CICFlowMeter statistics (volume, direction, timing, burstiness) plus packet-shape entropy.

**Intended use:** research and lab testbeds; a second opinion beside the LLM defender agent. **Not** validated for production networks (see Limitations).

**Deployed profile:** `robust` · trained 2026-11-12T19:47:00.296568+00:00 · python 3.13.18, scikit-learn 1.9.1

## Data

- 744 flows from 258 captures (420 benign / 324 malicious, 144 evaded, 72 in held-out variants)
- Split (by capture): {'train': 445, 'val': 150, 'test': 149}. Grouped by capture; no capture spans two splits.
- All traffic is **synthetic lab traffic** generated by this repository's testbed.
- Admissible features only: identity fields (IPs, ports, clock) and label-bearing fields are excluded (`veritas/features.py`).

## Method

Grouped (by capture) stratified cross-validation over logistic regression, random forest, extra trees and gradient boosting; best deployable family by out-of-fold F1; decision threshold from out-of-fold predictions at FPR ≤ 0.01. Held-out evasion variants are never trained on.

## Limitations (read before relying on any number above)

- **Lab traffic, not the internet.** Attacks are scripted by this repository and benign traffic is a handful of scripted HTTP/3 patterns. High scores show the pipeline works and that these generators are separable; they are not evidence about real-world QUIC traffic.
- **Small corpus.** Intervals above are wide when the smallest class is under 30 flows.
- **Evasion.** A model trained on clean traffic only is expected to be evaded by reshaped traffic; the `robust` profile narrows but does not remove that gap, and held-out variants estimate how much is left against evasion it has not seen.
- **Novel attack types.** See "Attack types the model never saw": recall on an attack whose behaviour differs from the trained ones can fall to 0%. This is a supervised detector of known behaviours, not an anomaly detector; retrain when new attack classes appear.
- **Not a replacement for payload inspection or host telemetry**; QUIC payloads are encrypted.
- Model files are scikit-learn pickles: load only files you built yourself or trust.
